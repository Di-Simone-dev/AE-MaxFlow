Detailed Description

Implementazione dei metodi di CapacityScaling.

Contiene i costruttori, il dispatcher max_flow() e le implementazioni private dell'algoritmo Capacity Scaling per le due modalità:

  • _max_flow_int per capacità long long (aritmetica esatta).
  • _max_flow_dbl per capacità double (confronti con soglia EPS).

La struttura è intenzionalmente duplicata (anziché templatizzata) per rendere esplicita la differenza nei confronti numerici tra le due modalità, in modo speculare a quanto fatto in push_relabel.cpp.
